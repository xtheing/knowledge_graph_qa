# 知识图谱问答系统 - 前端可视化界面设计文档

**日期**: 2026-02-01  
**版本**: 1.0  
**主题**: 前端可视化界面架构设计

---

## 1. 项目概述

### 1.1 目标
为知识图谱问答系统构建现代化、美观的前端可视化界面，提供直观的论文管理、知识图谱浏览、智能问答和实体搜索功能。

### 1.2 核心功能
- 📄 **论文管理** - 上传PDF、查看论文列表、删除论文
- 🔍 **知识图谱可视化** - 交互式图谱浏览、实体详情、关系探索
- 💬 **问答助手** - 自然语言提问、智能答案、上下文展示
- 🗂️ **实体浏览器** - 搜索实体、按类型筛选、查看详情

---

## 2. 技术栈

### 2.1 核心框架

| 技术 | 版本 | 用途 |
|------|------|------|
| **React** | 18.x | 前端框架 |
| **AntV G6** | 5.x | 图可视化引擎 |
| **Ant Design** | 5.x | UI组件库 |
| **Vite** | 5.x | 构建工具 |
| **React Router** | 6.x | 路由管理 |
| **Axios** | 1.x | HTTP客户端 |

### 2.2 技术选型理由

**React 18**: 
- 成熟的组件化框架，生态丰富
- Concurrent Features提升用户体验
- 强大的开发者工具支持

**AntV G6**:
- 阿里开源的专业图可视化引擎
- 内置力导向布局，支持10万+节点流畅渲染
- 丰富的交互功能（拖拽、缩放、选中、高亮）
- API设计友好，文档完善，中文支持好

**Ant Design**:
- 企业级UI设计语言和React组件库
- 提供完整的组件体系（表单、表格、卡片、抽屉等）
- 支持主题定制，适应不同风格需求

**Vite**:
- 极速的开发服务器启动（比CRA快10倍）
- 即时的模块热更新（HMR）
- 优化的生产构建输出

## 5. 数据流设计

### 5.1 API接口对接

前端通过RESTful API与后端交互：

```javascript
// API端点映射
const API = {
  // 健康检查
  health: '/health',
  
  // 问答
  ask: '/ask',
  
  // 论文管理
  uploadPaper: '/papers/upload',
  deletePaper: (id) => `/papers/${id}`,
  getPaperEntities: (id) => `/papers/${id}/entities`,
  
  // 实体查询
  searchEntities: '/entities/search',
  getEntityNeighbors: (name) => `/entities/${name}/neighbors`,
  
  // 统计
  getStats: '/stats'
}
```

### 5.2 状态管理

使用React Context + Hooks进行状态管理：

```javascript
// 主要状态
- papers: 论文列表
- currentPaper: 当前选中论文
- graphData: 图谱数据 { nodes, edges }
- chatHistory: 聊天历史
- entities: 实体列表
- loading: 全局加载状态
- error: 错误信息
```

## 6. 交互设计

### 6.1 知识图谱交互

|------|------|

| 操作 | 效果 |
|------|------|
| 输入问题 | 启用发送按钮 |
| 点击发送 | 显示加载动画，请求API |

## 7. 性能优化

### 7.1 图谱渲染优化
- 使用AntV G6的WebGL渲染模式
- 节点超过1000时启用聚合显示
- 实现虚拟滚动（节点详情列表）

### 7.2 数据加载优化
- 论文列表分页加载（每页12个）
- 实体列表分页加载（每页24个）
- 图谱数据按需加载（先加载1跳邻居）

### 7.3 缓存策略
- 使用React Query缓存API响应
- 本地存储保存用户偏好设置
- 会话存储保存当前会话状态

## 8. 部署方案

### 8.1 Docker部署

前端也容器化，与后端一起部署：

```yaml
# docker-compose.yml 新增前端服务
services:
  frontend:
    build: ./frontend
    container_name: kg-frontend
    ports:
      - "80:80"
    environment:
      - REACT_APP_API_URL=http://localhost:8000
    depends_on:
      - kg-api
```

### 8.2 Nginx配置

```nginx
server {
    listen 80;
    server_name localhost;
    
    location / {
        root /usr/share/nginx/html;
        index index.html;
        try_files $uri $uri/ /index.html;
    }
    
    location /api {
        proxy_pass http://kg-api:8000;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
```
